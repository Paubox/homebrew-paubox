# homebrew-paubox

Homebrew tap for Paubox tools.

## Install

```sh
brew tap paubox/paubox
brew install paubox-cli
```

Or in one step (no separate tap command needed):

```sh
brew install paubox/paubox/paubox-cli
```

## Update

```sh
brew update && brew upgrade paubox-cli
```

## Packages

| Formula | Version | Description |
|---------|---------|-------------|
| `paubox-cli` | 0.1.3 | Official CLI for the Paubox HIPAA-compliant email API |
